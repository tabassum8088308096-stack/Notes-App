📝 Notes App

A simple Notes App built using HTML, CSS, and JavaScript that allows users to create, edit, and delete 
notes directly in the browser. Notes are saved using Local Storage, so data remains even after refreshing the page.

🚀 Features
Add, edit, and delete notes
Data saved in browser storage
Simple and responsive UI

🛠️ Technologies
HTML
CSS
JavaScript

▶️ Run Project
Download or clone the repository
Open index.html in your browser
